Multi-agent desks: when one assistant isn't enough

Split work into desks with clear lanes so agents stop stepping on each other.

Once you have more than a handful of routines, one agent juggling everything gets sloppy. Split it into desks.

One desk, one lane

Examples: an Email desk (triage, drafts), a Research desk (briefings), a Build desk (code and sites), a Calendar desk (scheduling). Each has its own brief and its own connectors.

One coordinator

Have a single "front desk" agent you talk to. It hands work to the right desk and brings back results. You manage one conversation, not five.

Shared notes, not shared chaos

Give desks a shared folder for reference facts (your preferences, standing decisions). Keep each desk's working files separate.

Different models for different jobs

It's normal to use Claude Code for one build, Codex or Antigravity for another, and a hosted assistant for inbox work. Pick per job; don't marry a tool.
