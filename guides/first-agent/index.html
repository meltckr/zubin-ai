Set up your first agent in one afternoon

Pick one tool, one job, and one folder. Get a real result before you get clever.

Most people stall because they try to set up "an AI assistant for everything." Don't. Give your first agent one boring, repeatable job you already do by hand.

1. Pick the tool by where the work lives

  • Work lives in code or files on your computer: a coding agent like Claude Code, Codex, or Antigravity.
  • Work lives in email, calendar, Slack, docs: a hosted assistant with connectors, like Grok Bot.
  • Not sure: start hosted. Less setup, fewer ways to break your machine.

2. Write a one-page brief

Every serious agent tool reads a standing instruction file (names vary: CLAUDE.md, AGENTS.md, a "memory" or "instructions" panel). Put in it: who you are, what the job is, what "done" looks like, and what it must never do.

Job: Every weekday, summarize new emails from vendors into 5 bullets.
Done looks like: one message to me, under 120 words, links included.
Never: reply to anyone, delete anything, or spend money.

3. Run it by hand three times

Before you automate anything, run the job manually and fix the brief after each run. Three clean runs in a row means it's ready for a schedule.

Rule of thumb: if you can't describe "done" in one sentence, the agent can't hit it either.
