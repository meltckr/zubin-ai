Claude Code, Codex, Antigravity: a working comparison

How the main coding agents differ in practice, and how to pick for a given job.

All of them can read a project, edit files, run commands, and fix their own errors. The differences are workflow, not magic.

Claude Code

Terminal and desktop app. Strong at exploring a messy codebase and multi-file changes. Reads CLAUDE.md for standing instructions.

Codex

CLI, editor, and a cloud mode that works in the background and opens a pull request for review. Reads AGENTS.md.

Antigravity

Google's agent-first editor. Lets you pick model and effort level, and has permission presets that control how often it stops to ask.

How to pick

  • Want to watch every change? Terminal or editor agent.
  • Want to hand it off and review later? A background/cloud mode that opens a PR.
  • Second opinion? Give the same brief to two tools and compare.
Tools change monthly. Check each one's current docs for pricing and model names before committing.
