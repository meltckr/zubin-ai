Cost control: keep agents from quietly burning money

Where agent costs come from and five habits that keep the bill boring.

Where the money goes

  • Subscriptions (the flat monthly plan)
  • Usage-based APIs that agents call (search, data, voice, image)
  • Hosting and "starter" plans you forgot you opened

Five habits

  1. No new paid service without a yes. Put it in the brief.
  2. Cap usage-based keys with the provider's spending limit, before you hand them over.
  3. Test with fake data. Tell build agents "no live API calls" until the logic works.
  4. Monthly subscription sweep. Have an agent list every recurring charge it can find; you cancel.
  5. Use the smaller model for routine work. Save the heavy model for hard problems.
