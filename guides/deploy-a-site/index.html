Deploy your first agent-built site for free

From prompt to a live public URL using GitHub Pages, without touching a server.

  1. Ask your coding agent for a static site: plain HTML and CSS, no build step, mobile-friendly.
  2. Have it create a GitHub repository and push the files.
  3. In the repo's Settings → Pages, publish from the main branch. You get a username.github.io/repo URL.
  4. Ask the agent to verify: every page returns status 200 and looks right on a phone.
  5. Add the basics: page titles and descriptions, sitemap.xml, robots.txt, and llms.txt so AI tools can read your site cleanly.

This site was built exactly that way.
