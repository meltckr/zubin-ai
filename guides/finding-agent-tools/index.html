Finding agent tools worth your time

How to scout new agent tools and apps, and how to judge them before you hand over access.

New agent tools launch every week. Names you'll run into include hosted assistants like Grok Bot, coding agents like Claude Code, Codex, and Antigravity, open agent projects like Hermes, and newer apps such as Muse, Dots, and Instinct. Features and pricing change fast, so treat this as a map, not a review, and always check each tool's current docs before you commit.

Where to find them

  • Official changelogs and launch posts from the companies themselves
  • GitHub trending and the README of open-source projects
  • Practitioners on X and YouTube who show real setups, not just demos
  • App store listings, for consumer apps (read the privacy section)

Sort before you try

  • Hosted assistant: lives in the cloud, connects to your apps.
  • Coding agent: works in files and a terminal.
  • Open-source agent: you run it yourself; more control, more setup.
  • Single-purpose app: does one job well; easy to try, hard to extend.

Five-question test

  1. Does it solve a job I already do every week?
  2. What exactly can it read, and what can it send or change?
  3. Can I require my approval before anything irreversible?
  4. What does it cost at real usage, not the trial?
  5. How do I export my data and disconnect it?
Try new tools on a low-stakes job with read-only access. Promote them only after a clean week.
