Connectors: giving an agent access without giving it the keys

How to hook agents up to email, calendar, Slack, Drive, and GitHub safely.

Connectors are what turn a chatbot into an assistant. They're also where the risk lives.

Connect read-first

Add one connector at a time. For the first week, use it only for reading: search, summarize, find. Writes (sending, editing, deleting) come later, behind approval.

Use the official route

Prefer the tool's built-in sign-in (OAuth) over pasting passwords or API keys into chat. If you must use a key, keep it in a config file the agent can use but never prints.

Scope it down

One folder, not the whole drive. One channel, not the whole workspace. One repo, not the whole account. You can always widen later.

Know how to unplug

Before connecting anything, find the "disconnect" or "revoke access" button. If you can't find it, don't connect it.
